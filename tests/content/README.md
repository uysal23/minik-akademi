# Content Validation Tests

Bu klasör Build Adımı 5 ve sonraki aşamalarda içerik doğrulama test senaryolarını tutar.

Zorunlu test sınıfları:
- valid activity passes,
- malformed JSON fails,
- duplicate activity id fails,
- unknown curriculumId fails,
- invalid SOURCE page range fails,
- EXTENSION/source mismatch fails,
- locked letter sequence violation fails,
- locked number range violation fails,
- punitive feedback fails schema,
- external URL/remote key fails,
- release mode missing audio fails,
- release mode missing visual fails,
- release mode unreviewed safety fails.

Gerçek fixture/test kodları içerik üretimi başladığında eklenecektir.
