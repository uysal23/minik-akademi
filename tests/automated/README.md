# Build Step 12 — Automated Test Suite

Bu klasör Minik Akademi'nin GitHub Actions üzerinde çalışan otomatik proje sözleşmesi testlerini içerir.

Kapsam:
- kilitli içerik sayıları ve benzersiz activity ID'leri,
- curriculum eşleşmesi,
- çocuk güvenliği bayrakları,
- EXTENSION ayrımı,
- Android izin/offline kuralları,
- runtime TTS/network istemcisi yasağı,
- navigation route bağlantıları,
- DataStore ilerleme kayıtları ve PIN hash kuralı,
- audio/visual runtime hook'ları,
- Kotlin JUnit model ve navigation testleri,
- mevcut content/audio/visual validator'ları,
- Android debug build.

Bu aşama emülatörlü manuel UI testi değildir. Manuel pedagojik/UI testleri resmi Build Adımı 13 kapsamındadır.
