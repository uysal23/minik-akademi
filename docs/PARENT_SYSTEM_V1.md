# Minik Akademi — Parent System V1

**Status:** LOCKED  
**Version:** 1.0  
**Build Step:** 4

## Giriş

Çocuk dashboard'unda küçük ebeveyn ikonu bulunur.

Akış:
1. yaklaşık 3 saniye basılı tut,
2. 4 haneli PIN,
3. Parent Dashboard.

## Dashboard

Gösterilir:
- aktif çocuk adı/avatarı,
- bugün çalışma süresi,
- haftalık aktif gün,
- tamamlanan etkinlik,
- son konu,
- Türkçe ilerleme,
- Matematik ilerleme,
- tekrar önerileri.

Çocuklar arası sıralama yapılmaz.

## Sekmeler

- Özet
- Öğrenme
- Ayarlar
- Profiller

## Öğrenme Ayarları

- günlük hedef süre,
- otomatik ilerleme,
- tekrar sıklığı,
- Türkçe seviye,
- Matematik seviye.

Kaynak müfredat kilitleri varsayılan olarak korunur.

## Ses Ayarları

- anlatıcı açık/kapalı,
- SFX açık/kapalı,
- müzik açık/kapalı,
- genel ses,
- konuşma hızı: 0.80x / 0.90x / 1.00x,
- **Örneği Dinle**.

Cihazın TTS sesi seçilemez; uygulama kendi offline paketli öğretmen sesini kullanır.
